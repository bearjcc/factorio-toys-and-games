# factorio-toys-and-games

Factorio 2.0 mod repository for **Toys & Games**, a board-game production side chain.

The playable mod is the [`toys-and-games/`](toys-and-games/README.md) folder. That folder is what Factorio loads.

## Install

Copy or symlink `toys-and-games/` into your Factorio mods directory:

- Windows: `%appdata%\Factorio\mods\`
- Linux: `~/.factorio/mods/`
- macOS: `~/Library/Application Support/Factorio/mods/`

Example on Linux or macOS:

```
ln -s "$(pwd)/toys-and-games" ~/.factorio/mods/toys-and-games
```

Enable **Toys & Games** in the Factorio mod menu (Factorio 2.0+).

See the mod [README](toys-and-games/README.md) for progression, settings, and optional mod compatibility.
